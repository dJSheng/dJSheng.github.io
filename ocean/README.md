# 蓝色经济职业导航站

## 项目简介

本项目是泉州海洋职业学院《Web前端应用基础》课程的综合实训项目，面向大一新生（HTML+CSS零基础）学生。项目旨在帮助学生了解海洋新兴产业、探索相关职业方向、规划个人发展路径。

## 功能特点

- **产业全景展示**：全面展示六大海洋新兴产业（新能源、生物医药、渔业、交通运输、油气、滨海旅游）
- **职业导航探索**：深入了解海洋产业相关职业，包括岗位职责、发展路径、从业者故事
- **AI智能匹配**：通过HTML表单实现AI职业匹配功能（学生无需编写JavaScript）
- **响应式设计**：适配不同屏幕尺寸，支持移动端访问

## 技术栈

- HTML5
- CSS3
- 纯静态实现（无JavaScript）

## 如何使用

1. 直接在浏览器中打开 `index.html` 文件
2. 或使用VS Code的Live Server插件启动本地服务器
3. 通过导航栏访问各个页面

## 学习要点

本项目适合作为HTML+CSS课程的实训案例，涵盖以下知识点：

### HTML知识点
- 文档结构（DOCTYPE、head、body）
- 语义化标签（header、nav、section、footer、article）
- 表单元素（form、input、select、textarea、button）
- 链接与导航（a标签、锚点链接）
- 列表结构（ul、ol、li）

### CSS知识点
- CSS变量与主题配色
- Flexbox弹性布局
- Grid网格布局
- 响应式设计（媒体查询）
- 渐变与阴影效果
- 过渡动画（transition）
- BEM命名规范
