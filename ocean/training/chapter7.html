7.1

常见问题解答

实训过程中常见的问题与解决方案

❓

Q1: 页面在浏览器中显示乱码怎么办？

A: 确保HTML文件的编码设置为UTF-8。在head标签中添加：

设置编码 
<meta charset="UTF-8">
❓

Q2: CSS样式没有生效怎么办？

A: 检查以下几点：

  • CSS文件路径是否正确
  • 选择器是否写错
  • 是否有语法错误（缺少分号、括号等）
  • 浏览器开发者工具查看元素的计算样式
❓

Q3: 图片无法显示怎么办？

A: 检查图片路径是否正确，建议使用相对路径。确保图片文件存在于指定位置。

❓

Q4: 布局在不同屏幕尺寸下错乱怎么办？

A: 使用媒体查询进行响应式设计：

媒体查询示例 
@media screen and (max-width: 768px) {
    /* 小屏幕样式 */
}
❓

Q5: 如何调试页面问题？

A: 使用浏览器开发者工具（F12）：

  • Elements面板：查看和修改HTML/CSS
  • Console面板：查看错误信息
  • Network面板：检查资源加载情况
7.2

CSS命名规范（BEM）

本项目采用BEM命名规范，结构清晰、易于维护

📐

BEM命名规范

BEM命名示例 
/* Block（块）- 独立的组件 */
.card { }

/* Element（元素）- 块的组成部分 */
.card__title { }
.card__content { }
.card__footer { }

/* Modifier（修饰符）- 状态或变体 */
.card--featured { }
.card--large { }
.card__title--highlight { }
Block

块

独立的组件，如 card、header、nav

Element

元素

块的组成部分，用双下划线连接，如 card__title

Modifier

修饰符

状态或变体，用双中划线连接，如 card--active
