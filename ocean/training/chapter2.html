HTML核心标签速查

回顾《Web前端应用基础》课程的HTML核心知识点

📋

文档结构标签

标签 作用 示例
<!DOCTYPE html> 声明文档类型 必须放在文档最前面
<html> 根元素 包含整个页面内容
<head> 头部信息 包含meta、title、link等
<body> 页面主体 包含可见的页面内容
🏗️

语义化标签

标签 作用 使用场景
<header> 页头 网站顶部导航区域
<nav> 导航 导航菜单区域
<main> 主要内容 页面主要内容区域
<section> 章节 内容分区
<article> 文章 独立的内容块
<footer> 页脚 网站底部区域
📝

文本标签

h1-h6

标题标签

h1最大，h6最小，用于页面标题层级

p

段落标签

用于包裹文本段落

span

行内元素

用于包裹文本，不换行

a

超链接

href属性指定目标地址

strong

加粗强调

表示重要内容，显示为粗体

em

斜体强调

表示强调内容，显示为斜体

表单标签

表单基本结构 
<form action="提交地址" method="POST">
    <label for="username">用户名</label>
    <input type="text" id="username" name="username">

    <label for="password">密码</label>
    <input type="password" id="password" name="password">

    <button type="submit">提交</button>
</form>
input类型 作用
type="text"单行文本输入
type="password"密码输入（隐藏显示）
type="email"邮箱输入
type="number"数字输入
type="checkbox"复选框
type="radio"单选按钮
type="submit"提交按钮

CSS核心属性速查

回顾CSS选择器与常用属性

🎯

选择器

选择器 语法 示例
元素选择器 tagName p { }
类选择器 .className .card { }
ID选择器 #idName #header { }
后代选择器 parent child .nav a { }
伪类选择器 selector:state a:hover { }
📦

盒模型属性

盒模型示意 
/* 盒模型组成 */
.box {
    width: 200px;          /* 内容宽度 */
    height: 100px;         /* 内容高度 */
    padding: 20px;         /* 内边距 */
    border: 1px solid #000; /* 边框 */
    margin: 10px;          /* 外边距 */
}

/* 盒模型计算方式 */
box-sizing: content-box;  /* 默认：width不含padding和border */
box-sizing: border-box;   /* 推荐：width包含padding和border */
💡
关键知识点

设置 box-sizing: border-box 后，width/height包含padding和border，更容易控制元素尺寸。

布局方法总结

掌握Flexbox、Grid和响应式设计

📐

Flexbox弹性布局

Flexbox基本用法 
/* 容器属性 */
.container {
    display: flex;              /* 开启弹性布局 */
    flex-direction: row;        /* 主轴方向：row/column */
    justify-content: center;    /* 主轴对齐 */
    align-items: center;        /* 交叉轴对齐 */
    flex-wrap: wrap;            /* 允许换行 */
    gap: 20px;                  /* 子元素间距 */
}

/* 子元素属性 */
.item {
    flex: 1;                    /* 自动填充剩余空间 */
    flex-shrink: 0;             /* 不缩小 */
}
✅
Flexbox常用场景

水平居中、垂直居中、等分布局、导航菜单、卡片列表等

🔲

Grid网格布局

Grid基本用法 
/* 容器属性 */
.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);  /* 3列等分 */
    grid-template-columns: 1fr 2fr 1fr;     /* 指定比例 */
    gap: 20px;                              /* 间距 */
}

/* 响应式网格 */
.responsive-grid {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
    gap: 20px;
}
📱

响应式设计

媒体查询 
/* 基本语法 */
@media screen and (max-width: 768px) {
    .container {
        width: 100%;
        padding: 10px;
    }

    .grid {
        grid-template-columns: 1fr;  /* 变为单列 */
    }
}

/* 常见断点 */
/* 手机: max-width: 480px */
/* 平板: max-width: 768px */
/* 小屏电脑: max-width: 992px */
⚠️
注意事项

移动端优先设计时，先写移动端样式，再用媒体查询添加大屏样式。这样代码更简洁，性能更好。
