5.1

AI职业匹配功能介绍

本项目的亮点功能，通过分析用户信息智能推荐职业方向

🤖

功能说明

AI职业匹配是本项目的亮点功能，通过分析用户的兴趣、技能和性格特点，智能推荐最适合的海洋职业方向。

💡
技术亮点

本项目的AI功能采用纯HTML表单实现，学生完全不需要编写JavaScript代码！只需理解HTML表单的基本用法即可。

5.2

实现原理

了解表单提交的工作流程

🔄

技术架构

工作流程 
┌─────────────────┐    表单提交    ┌─────────────────┐
│                 │ ────────────→ │                 │
│  用户填写表单    │               │   后端服务器     │
│  (HTML页面)     │               │   (AI处理)      │
│                 │ ←──────────── │                 │
└─────────────────┘   返回结果    └─────────────────┘

步骤说明：
1. 用户在HTML页面填写表单
2. 点击提交按钮，浏览器将数据发送到后端
3. 后端AI服务分析数据
4. 返回匹配结果页面

学生任务：

  • 编写HTML表单结构
  • 设计表单样式（CSS）
  • 设置表单的action属性（指向后端API地址）

不需要编写任何JavaScript代码来处理表单数据。

5.3

后端接口文档

了解表单提交的目标地址和参数格式

📡

API接口说明

POST
/api/ai-match

接口说明：AI职业匹配接口，接收用户填写的个人信息，返回匹配的职业推荐结果。

请求地址：

http://39.100.68.78:8087/api/ai-match

注意：本地测试时表单提交会发送到此服务器地址。如果服务器未启动或网络不通，提交可能会失败。

参数名 类型 必填 说明
interest string 是 感兴趣的产业方向
skills array 是 技能特长（可多选）
personality string 是 性格特点
education string 是 学历背景
notes string 否 其他补充说明

5.5

表单元素详解

理解各种表单元素的用法

📝

下拉选择框（select）

select示例 
<select name="interest" required>
    <option value="">请选择...</option>         <!-- 默认空选项 -->
    <option value="new-energy">海洋新能源</option> <!-- 实际值和技术文档对应 -->
</select>
  • <select>：下拉选择框容器
  • <option>：选项，value是提交给后端的值
  • required：必填验证
☑️

复选框（checkbox）

checkbox示例 
<label class="form-checkbox">
    <input type="checkbox" name="skills" value="technical">
    <span>技术动手能力强</span>
</label>
  • type="checkbox"：复选框类型
  • 多个同name的checkbox会被合并为数组提交
  • 用 <label> 包裹可以点击文字也能选中
📄

多行文本框（textarea）

textarea示例 
<textarea name="notes" placeholder="请输入..."></textarea>
  • <textarea>：多行文本输入
  • placeholder：占位提示文字
  • 可用CSS设置 min-height 控制高度

注意事项

常见问题解答

⚠️

本地测试说明

⚠️
本地测试说明

本项目的AI功能需要后端服务支持。在本地实训时，点击"开始AI匹配分析"按钮可能会显示"无法连接"或404错误，这是正常现象。

重点在于理解表单的编写方式，而非实际的数据处理。

❓

常见问题

Q1: name属性可以随便写吗？

A: 不可以！name属性必须与后端接口文档中定义的参数名完全一致，否则后端无法正确接收数据。

Q2: value属性的值是怎么来的？

A: value值也需要与后端约定好。例如"new-energy"代表海洋新能源，后端根据这个值进行匹配计算。

Q3: 为什么复选框的name都一样？

A: 同名的多个checkbox会被合并为一个数组提交。例如skills数组可能包含 ["technical", "outdoor"]。

Q4: 如何测试表单是否正确？

A: 可以先用 action="https://httpbin.org/post" 测试，这个网站会返回你提交的数据，方便调试。
