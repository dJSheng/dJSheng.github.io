本项目要做一个"绿色家园"环保宣传网页——一个单页面网站，用于宣传环保理念、展示环保行动和最新动态。采用纯前端技术（HTML + CSS + JavaScript）开发，不依赖任何框架，从零开始一步步搭建。

五、技术栈说明

🔧前端三大技术各做什么？

用盖房子来比喻网页开发最贴切：

HTML = 房子的骨架结构。决定页面有哪些内容：标题、段落、图片、按钮在哪里。就像砌墙、安门、开窗。

CSS = 房子的装修。决定样子好不好看：颜色、大小、位置、动画。就像刷漆、铺地砖、装灯。

JavaScript = 房子的电器和智能系统。决定交互行为：点击有反应、滚动有动画。就像开关、门铃、自动窗帘。

本项目三者都会用到，但以 HTML + CSS 为主，JavaScript 只在最后实现少量交互。

一、新建项目根目录

  1. 在电脑桌面（或其他你习惯的位置）右键 → 新建 → 文件夹

🔧为什么要"打开文件夹"而不是"打开文件"？

如果只打开单个 HTML 文件，VS Code 无法管理同目录下的其他文件（如图片、CSS），路径提示和 Live Server 等功能会失效。打开整个文件夹后，VS Code 把它当作一个"项目"，左侧能看到所有文件，方便切换和管理。

另一种快捷方式：在文件夹上右键 → "通过 Code 打开"（前提是安装 VS Code 时勾选了右键菜单选项）。

引入 Font Awesome 图标库

为网页注入矢量小图标

🎯
本节学习目标
理解图标库的作用，正确引入 Font Awesome CSS 文件，学会用 <i> 标签显示图标。

一、为什么要用图标库

看看我们项目中有多少图标：导航的树叶、Banner 的回收标志、行动卡片的自行车/购物袋/闪电、新闻的日历、页脚的微博/微信/QQ……

如果每个图标都自己画或下载图片，太麻烦了！Font Awesome 是最流行的网页图标字体库，它把几百个图标做成了字体——你可以像设置文字一样，用 CSS 控制图标的大小、颜色，而且放大不失真。

🔧图标字体 vs 普通图片，为什么用图标字体？
对比项图标字体（Font Awesome）普通图片（PNG/JPG）
放大效果✅ 矢量，放大不模糊❌ 放大会模糊
改颜色✅ CSS 一行代码改 color❌ 需重新做图
文件大小✅ 一个字体文件含数百图标❌ 每个图标一个文件
加载速度✅ 快❌ 多个请求较慢

二、引入 CSS 文件

Font Awesome 本质上是一个 CSS 文���（配合字体文件），我们用 <link> 标签引入它。在 HTML 的 <head> 标签内（<title> 标签下方）添加：

HTML放在 <head> 内
<link rel="stylesheet" href="./font-awesome.min.css">
属性含义说明
rel="stylesheet"rel = relationship（关系），告诉浏览器这是一个样式表文件
href="./..."指定 CSS 文件的路径。./ 表示"当前文件夹"
🔧相对路径详解：./、../ 是什么意思？

路径就是"告诉浏览器去哪里找文件"。相对路径是相对于当前 HTML 文件所在位置：

./font-awesome.min.css → 当前文件夹里的 font-awesome.min.css

./img/1.jpg → 当前文件夹里 img 子文件夹中的 1.jpg

../style.css → 上一级文件夹中的 style.css（../ = 返回上一层）

本项目 HTML 和 font-awesome.min.css 在同一文件夹，所以用 ./font-awesome.min.css。

⚠易错点：图标显示为方框或不显示
最常见的错误就是路径写错或文件位置不对。排查方法：
  • ① 按 F12 打开浏览器控制台 → Console 面板
  • ② 如果看到 404 Not Found 红色报错，说明路径错误，文件没找到
  • ③ 检查 font-awesome.min.css 是否和 HTML 文件在同一文件夹
  • ④ 检查 img 文件夹内是否有 fa-*.ttf 和 fa-*.woff2 字体文件

一、编写完整的 head 区域

把用 ! 生成的代码，修改成如下内容（这就是我们项目的基础骨架）：

    <title>绿色家园 - 环保宣传</title>

    </style>

    <!-- 网页可见内容将在后续步骤中逐步添加 -->

</html>

二、逐行详细解释

代码作用说明
<!DOCTYPE html>文档类型声明，告诉浏览器这是 HTML5 文档。必须放在第一行，不写会导致浏览器进入"怪异模式"，样式可能错乱。
<html lang="zh-CN">整个网页的根标签。lang="zh-CN" 声明语言为简体中文，有助于浏览器翻译、搜索引擎收录、屏幕阅读器正确朗读。
<head>头部区域，放看不见的配置信息：字符编码、标题、引入的 CSS 等，不显示在页面上。
charset="UTF-8"字符编码设为 UTF-8，确保中文不乱码��不写可能出现"锘�"等乱码。UTF-8 是目前通用的编码标准。
viewport...视口设置，让网页在手机上也能正常显示。没有这行，手机浏览器会把网页缩小成一团看不清。
<title>网页标题，显���在浏览器标签页上，也是搜索引擎结果中的标题文字。
<link ...>引入外部 CSS 文件（上一步的 Font Awesome）。
<style>内嵌 CSS 样式标签。本项目所有 CSS 都写在这里面（教学便于管理）。
<body>主体区域，放用户能看见的所有内容：文字、图片、按钮等。后续步骤的代码都写在这里。
🔧HTML 标签的基本语法

<标签名 属性="值">内容</标签名>

例如：<p>这是一段文字</p>

  • 开始标签：<p>
  • 内容：标签中间的文字或其他标签
  • 结束标签：</p>（比开始标签多一个 /）
  • 自闭合标签：如 <meta>、<link>、<img> 没有结束标签，因为它们不包裹内容
🔧head 和 body 有什么区别？

head（头部）：放"幕后配置"——编码、标题、CSS、SEO 信息。用户看不到 head 里的内容（除了 title 显示在标签页）。

body（主体）：放"台前内容"——用户在页面上看到的一切文字、图片、按钮都在 body 里。

记住：看不到的配置放 head，看得到的内容放 body。

二、全局重置（去掉默认间距）

浏览器对某些标签有默认样式（比如 body 有 8px 外边距、ul 有左缩进、p 有上下间距），这些默认样式在不同浏览器还不一样，会影响布局。所以我们先统一清零：

CSS全局重置

    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
代码含义
*通配符选择器，匹配页面上所有标签。
margin: 0; padding: 0;���所有元素的外边距和内边距清零，消除浏览器默认间距。
box-sizing: border-box最重要的一行！改变盒模型计算方式（下面详解）。
🔧box-sizing：盒模型的核心知识点（必懂！）

每个 HTML 元素都是一个盒子，由四层组成（从内到外）：

内容（content）→ 内边距（padding）→ 边框（border）→ 外边距（margin）

关键区别在于盒子的总宽度怎么算：

❌ 默认（content-box）：你设 width:200px，再加 padding:20px，盒子实际变成 240px（200+20+20）。加 border 又会更大。越加越多，布局容易错乱。

✅ border-box：你设 width:200px，无论加多少 padding 和 border，盒子总宽度始终是 200px。padding 和 border 会向内挤压内容区。布局稳定，推荐始终使用。

这就是为什么几乎所有项目开头都要写 box-sizing: border-box。

代码含义

🔧margin: 0 auto 为什么能居中？（经典面试题）

当元素有固定宽度（或 max-width）时，左右 margin 设为 auto，浏览器会自动平均分配左右剩余空间，从而实现水平居中。

前提条件：① 元素必须是块级元素（div、p、section 等）；② 元素必须有明确宽度（没有宽度，auto 就没意义了）。

注意：margin: auto 只能水平居中，垂直居中要用 Flex 或其他方法。

属性含义详解
position: fixed固定定位，元素固定在浏览器视口的指定位置，不随页面滚动而移动（就像钉在屏幕上）。设置后需配合 top/left 定位。

🔧position 定位详解（重要知识点）

position 有 4 个常用值：

static（默认）：正常文档流，从上到下排列，top/left 无效。

relative（相对定位）：相对自己原本的位置偏移，不脱离文档流（占的位置还在）。

absolute（绝对定位）：脱离文档流，相对最近的已定位祖先元素（没有就相对 body）定位。

fixed（固定定位）：脱离文档流，相对浏览器视口定位，滚动时不移动。本项目导航栏就用这个。

🔧Flex 布局详解（现代布局核心！必学）

Flex（弹性盒子）是目前最常用的布局方式。给父元素加 display: flex，它的子元素就会自动横向排列（默认），并且可以用以下属性控制：

justify-content（主轴/水平方向对齐）：

  • flex-start：靠左排列（默认）
  • center：居中
  • space-between：两端对齐，首尾贴边，中间均分
  • space-around：每个项目两侧等距
  • space-evenly：所有间距完全相等

align-items（交叉轴/垂直方向对齐）：

  • center：垂直居中
  • flex-start：顶部对齐
  • flex-end：底部对齐

gap：子元素之间的间距（很实用的属性）

导航栏用 justify-content: space-between 让 Logo 靠左、菜单靠右，align-items: center 让它们垂直居中。

三、菜单悬停下划线动画（伪元素技巧）

继续添加菜单链接样式，实现纯 CSS 的悬停下划线滑入效果：

.nav-menu a {
    text-decoration: none;
    color: var(--dark);
    font-weight: 500;
    position: relative;   /* 关键：相对定位 */
    transition: var(--transition);
}

/* ::after 伪元素 = 隐形的下划线 */
.nav-menu a::after {
    content: "";
    position: absolute;
    bottom: -6px;
    left: 0;
    width: 0;              /* 初始宽度 0，看不见 */

    background: var(--green-accent);
    transition: var(--transition);
}

/* 悬停：文字变绿 + 下划线展开 */

.nav-menu a:hover::after { width: 100%; }
🔧伪元素 ::before 和 ::after（必学技巧）

伪元素可以在元素内部插入虚拟内容，不需要在 HTML 中额外加标签：

::before → 在元素内容前面插入

::after → 在元素内容后面插入

必须配合 content 属性才能显示（哪怕 content 为空也要写 content: ""）。

下划线动画原理：① 用 ::after 创建一条看不见的下划线（width:0）；② 父元素设 position: relative，伪元素设 position: absolute 精确定位在文字下方；③ 鼠标悬停时 width 变为 100%，配合 transition 实现从左向右滑入的动画。

🔧transition 过渡动画（让变化变平滑）

transition 让 CSS 属性的变化不是瞬间完成，而是平滑过渡。

语法：transition: 属性名 持续时间 缓动函数

本项目定义了变量 --transition: all 0.35s cubic-bezier(0.4,0,0.2,1)，意思是所有属性变化都用 0.35 秒平滑过渡，缓动函数让动画更自然（先快后慢）。

没有 transition，鼠标悬停时颜色、宽度会瞬间跳变，加上后就有丝滑的动画效果。

🔧transform 变换详解

transform 用于变换元素（移动、缩放、旋转、倾斜），不会影响其他元素布局：

  • translateY(-3px)：Y轴（垂直）移动，负数向上，正数向下
  • translateX(10px)：X轴（水平）移动
  • scale(1.1)：放大到 1.1 倍
  • rotate(45deg)：旋转 45 度

为什么用 transform 而不是 margin/top？因为 transform 不会触发布局重排，性能更好，动画更流畅。

🔧@keyframes 关键帧动画详解（让元素动起来）

@keyframes 用于定义自定义动画，指定在不同时间点的状态：

@keyframes 动画名 { 0%{...} 50%{...} 100%{...} }

  • 0% = 动画开始时的状态
  • 50% = 动画中间的状态
  • 100% = 动画结束时的状态（与 0% 相同则循环无缝）

本项目的 float 动画：0% 原位 → 50% 上浮 18px 并旋转 8° → 100% 回到原位，循环往复。

animation 简写语法：animation: 动画名 持续时间 缓动函数 循环次数 延迟

例：float 6s ease-in-out infinite 1s = 用 float 动画，6秒一轮，缓入缓出，无限循环，延迟1秒开始

💡

⚠易错点：z-index 层级混乱
Banner 内有三层：背景光晕（::before）、装饰圆、文字内容。必须确保文字在最上层。设置：z-index: 文字(2) > 装饰圆(1) > 背景(默认0)。如果文字被遮挡，检查 z-index 是否正确。

一、为动画元素添加 reveal 类

二、编写 reveal 初始样式

CSS动画初始/激活状态
/* ===== 滚动进入动画 ===== */
.reveal {
    opacity: 0;              /* 初始透明 */
    transform: translateY(40px);  /* 初始下移 40px */
    transition: opacity 0.7s ease, transform 0.7s ease;
}

    opacity: 1;            /* 显示 */
    transform: translateY(0);  /* 回到原位 */
}

三、编写 JavaScript 代码

在 </body> 标签之前添加 <script>：

JavaScript完整交互逻辑
<script>
    // ===== 1. 滚动出现动画 =====
    // 获取所有带 reveal 类的元素
    const revealEls = document.querySelectorAll('.reveal');

    // 创建交叉观察器
    const observer = new IntersectionObserver((entries) => {
        entries.forEach((entry, i) => {
            if (entry.isIntersecting) {
                // ���入视口后延迟添加 active（制造依次出现）
                setTimeout(() => entry.target.classList.add('active'), i * 120);
                observer.unobserve(entry.target);  // 只触发一次
            }
        });
    }, { threshold: 0.15 });

    revealEls.forEach(el => observer.observe(el));

    // ===== 2. 返回顶部按钮 =====
    const backTop = document.getElementById('backToTop');

    window.addEventListener('scroll', () => {
        backTop.classList.toggle('visible', window.scrollY > 400);
    });

    backTop.addEventListener('click', (e) => {
        e.preventDefault();  // 阻止默认跳转
        window.scrollTo({ top: 0, behavior: 'smooth' });
    });
</script>
代码含义
querySelectorAll('.reveal')选取页面上所有 class 含 reveal 的元素，返回一个列表
getElementById('backToTop')通过 id 选取单个元素
addEventListener('scroll', ...)监听滚动事件，每次滚动都执行函数
classList.toggle('visible', 条件)条件为 true 时添加类，false 时移除类
classList.add('active')给元素添加 active 类
e.preventDefault()阻止默认行为（阻止 a 标签跳转）
scrollTo({top:0, behavior:'smooth'})平滑滚动到页面顶部
🔧IntersectionObserver 滚动监听详解

它用来观察一个元素是否进入浏览器可视区域。比传统的 scroll + getBoundingClientRect 方案性能好得多（不需要频繁计算位置）。

工作流程：

  • ① observe(el)：开始观察某个元素
  • ② 当元素进入视口，触发回调函数
  • ③ entry.isIntersecting 为 true，说明进入了视口
  • ④ 给元素加 active 类 → CSS 动画触发
  • ⑤ unobserve(el)：停止观察（只触发一次）

threshold: 0.15 表示元素露出 15%时才触发回调。

🔧为什么 script 要写在 body 最后？

浏览器从上到下解析 HTML。如果 script 写在 head 中，执行 JS 时 HTML 还没加载完，getElementById 会找不到元素返回 null。

把 script 放在 </body> 之前，确保所有 HTML 元素都已加载，JS 才能正确操作它们。

⚠易错点：动画不生效
排查：
① 元素是否加了 reveal 类？
② CSS 是否定义了 .reveal 和 .reveal.active？
③ script 是否在 body 最后？
④ id 拼写是否一致（backToTop）？
📝本节小结
  • querySelectorAll / getElementById 选取元素
  • addEventListener 监听事件（scroll、click）
  • classList.add / toggle 操作类名
  • IntersectionObserver 高性能监听元素进入视口
  • script 必须放在 body 末尾，确保 DOM 已加载
