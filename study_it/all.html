数据、信息与知识

三个高频概念——数据、信息、知识，以及它们"由低到高"的关系。配套教材单元练习 30 题。

⭐ 重点

📊一、数据：现实世界客观事物的符号记录

数据是现实世界客观事物的符号记录，是信息的载体；而信息是数据的内涵（含义），是对数据的语义解释。

🔍 例子："小明的身高是 160 厘米"这句话描述的是信息，其中的 160 才是数据。

数据的分类（两种分法，注意区分）：

划分角度类别举例
按处理方式数值型数据（含正负号、小数点、数字）年龄、收入、物价、气温
按处理方式非数值型数据文字、图像、声音、视频
按表现形式数字数据（二进制数）计算机内部用 0、1 表示
按表现形式模拟数据符号、语言、文字、图像、动画、声音、视频

数据的特点：有些数据固定不变（电话区号、邮政编码）；有些会变化（气温、身高体重、价格）；有些随机出现（彩票开奖号码、抛骰子点数）。

⭐ 重点

🌐二、大数据：无法常规处理的数据集合

大数据是指无法在可承受的时间范围内用常规软件工具进行高效捕捉、管理和处理的数据集合。大数据起源于互联网。

📌 记忆口诀："量大类多速度快，价值密度低一半"（体量大·类型多·速度快·价值密度低）
特征含义
数据体量大数据规模巨大
数据类型多数据多样且变化快
处理速度快实时处理、秒级响应
价值密度低数据量大但单条价值低，需挖掘

应用：电商个性化推荐、导航地图、健康码、行程码、掌上公交。采集方法：网络采集法（爬虫）、传感器采集法、系统日志采集法。处理过程：采集与预处理 → 存储 → 挖掘 → 呈现。

⭐ 重点🔥 难点

💡三、信息：数据的内涵（八大特征）

三大经典定义：香农——"信息可以消除认识上的不确定性"；维纳——"信息是一种资源"（与物质、能量并列三大资源）；钟义信——"信息是事物运动的状态与状态变化的方式"。

信息必须依附于某种载体（符号、语言、文字、图像、声音、动画、视频）才能存储、表达和传播。

📌 记忆口诀："价值依附可处理，传递共享讲时效，真伪相对记心间"（价·依·可·传·共·时·真·相）
特征关键词典型例子
价值性有经济/精神价值、指导决策天气预报作穿衣出行参考
载体依附性不能独立存在、需载体文字刻竹简、写在纸上、存电脑
可处理性加工后增值、产生新信息气象部门分析卫星云图得预报
传递性从一地传播到另一地冬奥会开幕式全球直播
共享性多人同时使用、不减少红绿灯信号每个司机都能看到
时效性过时失效、有时间段微信红包 24 小时未领自动退回
真伪性有真有假"空城计""减灶退敌"、诈骗短信
价值相对性对不同人价值不同酒驾扣 12 分对司机重要、对小学生没用
⭐ 重点

🧠四、知识：对信息加工提炼的结果

知识是对信息加工、提炼、分析的结果，能精准反映事物的本质，是人们在改造世界的实践中获得的可用于指导实践的认识、规律和经验。

🔍 辨析："感冒指数、健康指数、数理化公式定理"是知识；"标准气压下冰水混合物温度是 0℃"这句话描述的是知识。
📌 DIKW 金字塔：数据 → 信息 → 知识 → 智慧（由低到高，数据是基础、最初阶段）

数据、信息、知识是人类认知客观世界由低到高的三个阶段：数据是原料（载体），信息是内涵（语义），知识是规律（升华）。

⭐ 重点🔥 难点

🔢五、学会找数据规律（找规律题型套路）

教材原题：数列 1, 2, 6, 11, 20 的下一个数是 34（前 2 项相加的和再加 3 等于下一项）；数列 1, 3, 7, 13, 21 的下一个数是 31（第 n 项 = 第 n-1 项 + (n-1)×2）。

📌 找规律三板斧："一看差、二看比、三看前后项关系"
  • 一级等差：相邻两数差固定 → 49, 64, 81, 100, 121（7²,8²,9²…下一项 12²=144）。做差得 15,17,19,21 → 下一个差 23 → 121+23=144。
  • 二级等差：差不固定但"差的差"固定 → 1,3,7,13,21 做差得 2,4,6,8 → 下一个差 10 → 21+10=31。
  • 递推关系：前两项之和（±修正）→ 1,2,6,11,20：1+2+3=6，2+6+3=11，6+11+3=20，11+20+3=34。
  • 平方/立方数列：见到 49, 64, 81, 100, 121 先想到平方数列。
🔍 解题套路：先做差 → 差成等差则用二级等差；差是奇数递增想到平方数列；差乱则试"前两项相加"递推。综合训练一第 22 题（8,20,34,50,68 → 差 12,14,16,18 → 下一个差 20 → 88）即用此法。

数制、数据编码与存储单位

二进制与十进制互转、ASCII 码、汉字编码与存储单位换算。配套教材单元练习 30 题。

⭐ 重点🔥 难点

🔢一、二进制：计算机的"母语"

计算机内部所有数据都用二进制表示（只有 0、1 两个数码），运算规则是"逢二进一、借一当二"。n 进制的规则是"逢 n 进一、借一当 n"。二进制数末尾加字母 B 表示，如 1101B。

📌 转换口诀：十转二"除 2 取余倒着写"；二转十"按权展开求和"
十进制 → 二进制：除 2 取余法——反复除 2 记余数，商为 0 止，余数由下而上写出。
例：35 = 100011B（35→17余1→8余1→4余0→2余0→1余0→0余1）
二进制 → 十进制：按权展开法——各位数码 × 位权（2⁰=1, 2¹=2, 2²=4, 2³=8…）后求和。
例：(10111)₂ = 1+2+4+0+16 = 23
🔍 拆数法（凑数法）：35 = 32+2+1 → 100011；27 = 16+8+2+1 → 11011。按位权由大到小拆，每步尽可能大。
⭐ 重点

🔤二、ASCII 码：英文字符的编码

ASCII 码（美国信息交换标准代码）用于对英文字母（大小写不同）、数字 0~9、标点符号及控制字符编码。用一个字节表示一个字符，最高位固定为 0，实际只用 7 位，共能表示 2⁷=128 个字符。

📌 大小关系：空格 < 数字 < 大写字母 < 小写字母
ASCII 码（十进制）对应的字符
0 ~ 31控制字符
32空格
48 ~ 57数字 0 ~ 9
65 ~ 90大写字母 A ~ Z
97 ~ 122小写字母 a ~ z
🔍 推导法：已知 "d"=100，则 "g"=100+3=103；已知 "C"=01000011B，则 "F"=01000011+11B=01000110。
⭐ 重点🔥 难点

🈶三、汉字编码：输机国出四环节

汉字从输入到输出各环节的编码：输入码 → 机内码 → 国标码（GB2312）→ 输出码（字形码）。输入码包括拼音、五笔；机内码是汉字在机器内部存储、加工、传送使用的代码；国标码是一种交换码。

📌 记忆口诀："输机国出"（输入码 → 机内码 → 国标码 → 输出码）
存储一个汉字的机内码或国标码用 2 个字节；存储 1000 个汉字约占 2KB。
🔍 字形点阵："日"字 8×8 点阵，空白方块记 0、黑色方块记 1，从上往下第二行编码 01111110。存储该点阵占用 8×8÷8 = 8B（除以 8 把位转成字节）。
⭐ 重点

💾四、信息存储单位：bit 到 TB

存储信息的最小单位是位（bit，简记 b，即比特）；基本单位是字节（Byte，简记 B），1B = 8bit。

📌 换算链：1KB=1024B → 1MB=1024KB → 1GB=1024MB → 1TB=1024GB（相邻全是 1024，只有 B→bit 是 8）
🔍 常考换算：1KB 存 1024 个英文字符（1B/个）；1KB 存 512 个汉字（2B/个）；1024 个汉字国标码占 2KB；10000 个英文字母约 10KB。
📝 补充

🔄五、编码的意义与 R 进制通则

编码：按预先规定的方法将文字、数字或其他数据转换为规定的符号组合。在计算机中，编码是把符号、数字、文字、图像、声音、视频等编成二进制代码的过程。

📌 编码四大作用："便机器、易使用、省空间、提效率"（便于机器识别存储传输处理；方便使用提高利用率；节省存储空间；提高处理效率）

R 进制通则：n 进制"逢 n 进一、借一当 n"。四进制逢四进一、六进制逢六进一——题干换成任何进制，规则套用即可（综合训练八第 38 题考过六进制）。

声音与图像编码

模拟与数字信号、采样量化编码三步、容量计算公式与文件格式。配套教材单元练习 25 题。

⭐ 重点

〰️一、模拟信号与数字信号

模拟信号：用连续变化的物理量表达信息，相对不稳定、传播中易受干扰失真。用传感器直接获得的信号（声音、图像、视频、温度、压强）都是模拟信号，其值叫模拟数据。

数字信号：随时间变化离散、不连续的信号，其值称数字数据，用二进制 0 和 1 表示。模拟信号与数字信号可以相互转换。

⭐ 重点🔥 难点

🎵二、声音的数字化：采·量·码三步曲

将声音等模拟数据数字化的基本步骤：采样 → 量化 → 编码。

📌 记忆口诀："采量码"——采样（取幅度值）、量化（整数表示）、编码（转二进制）
  • 采样：每隔一段时间在波形上取一个幅度值；1 秒内的采样次数叫采样频率，越高保真度越高。
  • 量化：用二进制数表示采样所得幅度值；量化位数越大保真度越高。
  • 编码：把量化后的数据转化为二进制数。
声音数据容量（B）= 采样频率 × 量化位数 × 声道数 × 时长 ÷ 8
🔍 例题：22.05kHz、16 位、5 秒、双声道 → 22050×16×2×5÷8 = 441000B ≈ 430.7KB。

采样频率越高、量化位数越大 → 保真度越高、质量越好，但数据容量越大。

⭐ 重点🔥 难点

🖼️三、图像的数字化：像素与位深

图像数字化同样包含采样、量化、编码：采样即把画面分割成离散像素点；量化即把每个像素的颜色/亮度用二进制表示；编码即按格式记录各像素量化数据。

图像容量（B）= 分辨率 × 颜色位数（位深度）÷ 8
颜色种数 = 2ⁿ（n 为颜色位数）
🔍 例题：20×30 像素、24 位色 → 20×30×24÷8 = 1800B；16 色图像（2⁴=16，每像素 4 位）→ 20×30×4÷8 = 300B。

位图 vs 矢量图：位图由像素组成，放大易失真、容量大，但色彩丰富逼真；矢量图由线条加色块组成，放大不易失真、容量小，但色彩单调。

⬅️三、赋值语句的五种形式

🛡️一、信息安全风险与防范措施

🦠二、计算机病毒与黑客

计算机病毒是人为编制的有害程序（不是生物病毒、不是逻辑错误程序）。特点：破坏性、传染性、隐蔽性、潜伏性、激发性（可触发性）、寄生性。

📌 记忆："破传隐潜激寄"六字诀；主要传播途径：网络 + U盘
🔍 可触发性：病毒在系统日期"月+日=13"才发作。杀毒软件：360 杀毒、360 安全卫士、瑞星、金山毒霸、江民 KV——杀毒软件不能查杀所有病毒，病毒库升级滞后于新病毒。

黑客：计算机系统的非法侵入者。防黑客措施之一：安装防火墙（网络的安全屏障：隔离内外网、阻挡攻击、控制访问权限；安装在内网与外网之间）。
