📊一、数据：客观事物的符号记录

数据是现实世界客观事物的符号记录，是信息的载体；而信息是数据的内涵（含义），是对数据的语义解释。

🔍 例子：“小明的身高是 160 厘米”这句话描述的是信息，其中的 160 才是数据。

数据的分类（两种分法，注意区分，容易混淆）：

划分角度类别举例
按处理方式数值型数据（含正负号、小数点、阿拉伯数字）年龄、收入、物价、气温
按处理方式非数值型数据文字、图像、声音、视频
按表现形式数字数据（二进制数）计算机内部用 0、1 表示
按表现形式模拟数据符号、语言、文字、图像、动画、声音、视频

数据的特点：有些数据是固定的（如电话区号、邮政编码）；有些是会变化的（如气温、身高体重、物价）；有些是随机的（如彩票开奖号码、抛骰子点数）。

⭐ 重点🔥 难点

💡二、信息：数据中包含的意义

信息是数据中所包含的意义，必须依附于某种载体才能存储、表达和传播。典型信息：信号、通知、资讯、消息、短信、广告、新闻、市场行情、天气预报等。

三种经典定义（记住三位科学家）：

  • 香农：信息是能消除认识上的不确定性的消息。
  • 维纳：信息是一种资源，信息、物质、能量是人类赖以生存的三大资源。
  • 钟义信：信息是事物运动的状态与状态变化的方式。

信息的八大特征（考试高频，务必记牢）：

特征含义实例
价值性具有经济或精神价值天气预报指导穿衣、出行
载体依附性不能独立存在，需依附载体文字刻竹简、写纸上、存电脑
可处理性加工后产生新信息、增值卫星云图→天气预报
传递性可从一个地方传到别处冬奥会开幕式全球直播
共享性多人同时接收、可多次使用红绿灯信号每个司机都能看
时效性一定时间内有效，过期失效微信红包 24 小时未领自动退回
真伪性有真有假"空城计"、手机诈骗短信
价值相对性对不同人有不同价值酒驾扣分对司机重要、对学生无用

信息的载体：符号、语言、文字、图像、声音、动画、视频等。

📌 记忆口诀（信息八大特征）：
"价值依附可处理，传递共享讲时效，真伪相对记心间。"（价·依·可·传·共·时·真·相）
⭐ 重点

🧠三、知识 & 数据→信息→知识→智慧的关系

知识是对信息加工、提炼、分析的结果，能精准反映事物的本质，是可用于指导实践的认识、规律和经验。

🔍 例子：“标准气压下，冰水混合物的温度是 0℃”描述的是知识。公式、定理、感冒指数、身体健康指数、"血压正常范围""正常心率 60~100 次/分"都属于知识。

四者关系——由低到高的认知阶段：

数据 → 信息 → 知识 → 智慧
  • 数据：是信息和知识的基础（原料，最初阶段）；
  • 信息：是数据处理的结果（加工后有意义）；
  • 知识：是对信息加工、提炼的结果，反映本质（规律）；
  • 智慧：是知识的抽象和升华。

⚠️ 注意：数据与信息不是"相互包含"关系——数据是载体、信息是内涵。

📌 记忆口诀：
"数据是原料，信息是加工，知识是规律，智慧是升华。"
⭐ 重点

🌐四、大数据

大数据是指无法在可承受的时间范围内用常规软件工具进行高效捕捉、管理和处理的数据集合，起源于互联网。

四大特征（4 个关键词）：

  • 数据体量大（规模大）
  • 数据类型多（多样且变化快）
  • 处理速度快
  • 应用价值高但价值密度低

应用：电商个性化推荐、导航地图、健康码、行程码、掌上公交等。

采集方法：网络采集法（网络爬虫）、传感器采集法、系统日志采集法。

处理过程：数据采集与预处理 → 数据存储 → 数据挖掘 → 数据呈现。

⭐ 重点🔥 难点

🔢五、学会找数据规律（找规律题型套路）

找数据的规律（教材补充）：

🔍 数列 49, 64, 81, 100, 121 … 下一项是 144（7²、8²、9²、10²、11² → 12²）。
🔍 数列 1, 2, 6, 11, 20 … 下一项是 34（前两项相加再加 3）。
🔍 数列 1, 3, 7, 13, 21 … 下一项是 31（第 n 项 = 第 n−1 项 + (n−1)×2）。
📌 找规律三板斧："一看差、二看比、三看前后项关系"
  • 一级等差：相邻两数差固定 → 49, 64, 81, 100, 121（7²,8²,9²…下一项 12²=144）。做差得 15,17,19,21 → 下一个差 23 → 121+23=144。
  • 二级等差：差不固定但"差的差"固定 → 1,3,7,13,21 做差得 2,4,6,8 → 下一个差 10 → 21+10=31。
  • 递推关系：前两项之和（±修正）→ 1,2,6,11,20：1+2+3=6，2+6+3=11，6+11+3=20，11+20+3=34。
  • 平方/立方数列：见到 49, 64, 81, 100, 121 先想到平方数列。
🔍 解题套路：先做差 → 差成等差则用二级等差；差是奇数递增想到平方数列；差乱则试"前两项相加"递推。综合训练一第 22 题（8,20,34,50,68 → 差 12,14,16,18 → 下一个差 20 → 88）即用此法。

🔢一、二进制的基本概念

计算机内部所有数据都用二进制表示，只有 0、1 两个数码，能被机器直接识别。

运算规则：逢二进一、借一当二。同理，n 进制就是"逢 n 进一、借一当 n"（如四进制"逢四进一"、五进制"逢五进一"）。

位权（由低位到高位）：2⁰、2¹、2²、2³…… 即 1、2、4、8……

表示方式：在数末尾加字母 B，如 1101B 表示二进制。其余：D 十进制、O 八进制、H 十六进制。

组合状态数：n 位二进制有 2ⁿ 种组合（如 4 位二进制有 2⁴=16 种）。

十进制 → 二进制（两种方法）：

方法一：除 2 取余法（辗转相除法）——反复除以 2，取出余数，商作为下次被除数，直到商为 0，余数由下往上写。

🔍 例：35 → 100011B　35÷2=17 余1，17÷2=8 余1，8÷2=4 余0，4÷2=2 余0，2÷2=1 余0，1÷2=0 余1，余数倒序得 100011。

方法二：拆数法（凑数法）——按位权从大到小拆，每一步尽量大。

🔍 例：35 = 32 + 2 + 1 → 二进制 100011；　27 = 16 + 8 + 2 + 1 → 11011；　14 = 8 + 4 + 2 → 1110；　29 = 16 + 8 + 4 + 1 → 11101。

💡 通用方法：十进制转任意 R 进制（R=2、8、16），都用"除 R 取余、倒序排列"。

📌 记忆口诀：
"除 2 取余，余数倒着读；拆权凑数，从大往小拆。"

二进制 → 十进制（按权展开求和）：把各位数码乘以对应位权后相加。

🔍 例：(10111)₂ = 1×2⁰ + 1×2¹ + 1×2² + 0×2³ + 1×2⁴ = 1 + 2 + 4 + 0 + 16 = 23
🔍 例：(11010)₂ = 0 + 2 + 0 + 8 + 16 = 26；　(10101)₂ = 16 + 4 + 1 = 21
📌 记忆口诀：
"按权展开，乘了再加，位数从 0 开始数。"

🔤二、ASCII 码

ASCII 码是美国国家信息交换标准代码，用于对英文字母（区分大小写）、数字 0~9、标点及控制字符编码。

  • 用 1 个字节表示 1 个字符，最高位固定为 0，实际只用 7 位，共能表示 2⁷ = 128 个字符。
  • 大小关系（务必记住）：空格 < 数字 < 大写字母 < 小写字母

常用十进制范围：

范围内容
0 ~ 31控制字符
32空格
48 ~ 57数字 0 ~ 9
65 ~ 90大写字母 A ~ Z
97 ~ 122小写字母 a ~ z
123 ~ 128英文标点符号、运算符号
🔍 推导："d"=100 → "g"=100+3=103；"C"=01000011 → "F"=01000011+11=01000110；"B"=01000010 → "F"=01000010+100=01000110；"C"=67 → "H"=67+5=72。
📌 记忆口诀：
"空 < 数 < 大 < 小"（空格最小，小写字母最大；数字 48 起、大写 65 起、小写 97 起）。
⭐ 重点🔥 难点

🀄三、汉字编码流程

汉字从输入到输出，不同环节用不同编码：

输入码 → 机内码 → 国标码(GB2312) → 输出码(字形码)
  • 输入码：如拼音、五笔；
  • 机内码：汉字在机器内部存储、加工、传送使用的代码；
  • 国标码（GB2312）：一种交换码；
  • 输出码（字形码）：用字形点阵表示。

存储：存储一个汉字的机内码或国标码用 2 个字节，存储 1000 个汉字约占 2KB（1024 个汉字国标码 = 2048B = 2KB）。

🔍 字形点阵："日"字 8×8 点阵存储容量 = 8×8÷8 = 8B（÷8 是把"位"换算成"字节"，1B=8 位）。位图编码规则：黑记 1、白记 0，从左到右逐位编码。
📌 记忆口诀：
"输入 → 机内 → 国标 → 输出"，简称 "输机国出"；一个汉字机内码/国标码 2 字节。
⭐ 重点

💾四、信息存储单位

最小单位是位（bit，简记 b，即比特），基本单位是字节（Byte，简记 B），1B = 8bit。

1B = 8bit　|　1KB = 1024B　|　1MB = 1024KB　|　1GB = 1024MB　|　1TB = 1024GB
🔍 1KB 能存 1024 个英文字符（每个 1B），最多存 512 个汉字（每个 2B）；10000 个英文字母约 10KB。
📌 记忆口诀：
"1B 等于 8 位，1024 进一级，K、M、G、T 排排坐。"

🔄五、信息的编码

编码是指按预先规定的方法将文字、数字或其他数据转换为规定的符号组合。在计算机中，编码是指将符号、数字、文字、图像、声音和视频等对象按预先规定的方法编成二进制代码的过程。

编码的作用与意义（四点）：

  • 便于机器识别、存储、传输和处理；
  • 方便使用，提高数据利用率；
  • 节省存储空间；
  • 提高数据处理效率。

  • 汉字编码流程：输入码→机内码→国标码→输出码（"输机国出"）；每汉字 2B。
  • 换算链 1KB=1024B、1MB=1024KB、1GB=1024MB、1TB=1024GB。

〰️一、模拟信号与数字信号

🎵二、声音数字化

  • 采样：每隔一段时间在波形上取一个幅度值，1 秒内采样次数叫采样频率，频率越高保真度越高。
  • 量化：用二进制数表示采样得到的幅度值（取最接近的整数），量化位数越大保真度越高。
  • 编码：把量化后的数据转化为二进制数。

采样频率越高、量化位数越大 → 保真度越高、质量越好，但数据容量越大。

声音容量(B) = 采样频率 × 量化位数 × 声道数 × 时长 ÷ 8
🔍 例：22.05kHz、16 位、10 秒、双声道：22.05×1000×16×10×2÷8÷1024 ≈ 861.3KB。
🔍 例：22.05kHz、16 位、5 秒、双声道：22.05×1000×16×5×2÷8÷1024 ≈ 430.7KB。（注意 kHz 先 ×1000 换成 Hz）
📌 记忆口诀：
"频率乘位数，乘声道乘时长，最后除以 8。"

🖼三、图像数字化

图像数字化同样分采样、量化、编码三步：采样是把图像分割成像素点；量化是用二进制表示每个像素的颜色/亮度；编码是记录量化数据。

  • 像素：图像分割成的离散点。
  • 颜色位数（位深度）：表示像素点颜色/亮度的位数，颜色种数 = 2ⁿ（n 为颜色位数）。
🔍 黑白图像 1 位（2¹=2 色）、16 色需 4 位（2⁴）、256 色需 8 位（2⁸）、24 位真彩色；5 位可表示 2⁵=32 色。
图像容量(B) = 分辨率(宽×高) × 颜色位数 ÷ 8
🔍 例1：20×30、24 位：20×30×24÷8 = 1800B。　例2：20×30、16 色（4 位）：20×30×4÷8 = 300B。　例3：10×20、16 色：10×20×4÷8 = 100B。　例4：20×10、24 位：20×10×24÷8 = 600B。
📌 记忆口诀：
"分辨率乘位数，除以 8 得容量；颜色种数 2 的 n 次方。"

⬅️三、赋值语句的五种形式

执行顺序：①输入 a → ②输入 b → ③算 s → ④输出。四句一句不少、顺序不能乱——这就是顺序结构。
📌 记忆：顺序结构像"流水线"——从上到下逐条执行，不跳、不回头。读程序题永远从第一行往下走。

辨析：只有顺序结构解决不了"分类判断"（如成绩分级）和"重复计算"（如 1+2+…+100）的问题——所以才需要分支结构和循环结构（见后两张卡）。

⭐ 重点🔥 难点

🔀二、分支结构：if / elif / else

单分支：if 条件: 语句块
双分支：if 条件: 语句块1 else: 语句块2
多分支：if 条件1: … elif 条件2: … else: …

语句块必须缩进（4 空格），缩进是 Python 程序结构的标志。多分支只有一个语句块被执行。

🔍 判断偶数：if a%2==0: print("是偶数")
三分类：if a>0: b="正数" elif a==0: b="零" else: b="负数"
⭐ 重点🔥 难点

🔁三、计数循环 for：次数已知

for 循环变量 in 序列: 语句块

序列可以是列表、字符串、range() 函数。

🔍 四大经典模型：

♾️四、条件循环 while：次数未知

while 条件表达式: 语句块

条件为真一直循环，为假退出；若一开始条件为假，循环体一次也不执行。三要素：循环变量、循环体、循环终止条件。

💻二、计算机系统：硬件五大部件

📌 存储器口诀："RAM 随机断电丢，ROM 只读断电留"

  • 缓存（Cache）：存储器分内存、外存、缓存三类，Cache 用于 CPU 与内存间加速。

🌐一、网络功能、分类与设备

网络三大功能：资源共享（本质功能）、数据通信（传输）、分布处理。

按覆盖范围分类：局域网 LAN（几米~几千米，一栋楼/一校园，速度快误码率低）→ 城域网 MAN（几十~上百千米，覆盖城市）→ 广域网 WAN（几十~几千千米，国家/洲际，如互联网）。

网络设备：网卡（物理连接计算机与传输介质）、路由器、交换机、集线器、调制解调器（MODEM"猫"：电话线上网，数字↔模拟转换）；"光猫"：光信号↔数字信号转换。传输介质：有线——双绞线（局域网常用）、光纤（速度快抗干扰强、互联网主干）、同轴电缆；无线——红外、无线电波、微波（手机连 Wi-Fi）、激光、卫星。

常用协议：TCP/IP（互联网主协议簇）、FTP（文件传输）、SMTP（发邮件）、HTTP（浏览器与 WWW 通信）。

补充考点

按拓扑结构分类：总线型、星型、环型、网状型四类。

互联网六大应用：信息浏览（www）、电子邮件（E-mail）、文件传输（FTP）、远程登录（Telnet）、电子商务、远程教育与远程医疗。

信息交流方式：即时通信——QQ、微信、阿里旺旺、钉钉；非即时通信——电子邮件（E-mail）、BBS、博客、微博。邮件地址格式：用户名@邮局域名；Outlook 是收发邮件客户端。
