第 1 课时

数据、信息与知识

搞清楚三个高频概念——数据、信息、知识，以及它们"由低到高"的关系。本课时配套教材单元一 30 道真题。

⭐ 重点🔥 难点

📊一、数据：客观事物的符号记录

数据是现实世界客观事物的符号记录，是信息的载体；而信息是数据的内涵（含义），是对数据的语义解释。

🔍 例子：“小明的身高是 160 厘米”这句话描述的是信息，其中的 160 才是数据。

数据的分类（两种分法，注意区分，容易混淆）：

划分角度类别举例
按处理方式数值型数据（含正负号、小数点、阿拉伯数字）年龄、收入、物价、气温
按处理方式非数值型数据文字、图像、声音、视频
按表现形式数字数据（二进制数）计算机内部用 0、1 表示
按表现形式模拟数据符号、语言、文字、图像、动画、声音、视频

数据的特点：有些数据是固定的（如电话区号、邮政编码）；有些是会变化的（如气温、身高体重、物价）；有些是随机的（如彩票开奖号码、抛骰子点数）。

找数据的规律（教材补充）：

🔍 数列 49, 64, 81, 100, 121 … 下一项是 144（7²、8²、9²、10²、11² → 12²）。
🔍 数列 1, 2, 6, 11, 20 … 下一项是 34（前两项相加再加 3）。
🔍 数列 1, 3, 7, 13, 21 … 下一项是 31（第 n 项 = 第 n−1 项 + (n−1)×2）。
⭐ 重点

🌐二、大数据

大数据是指无法在可承受的时间范围内用常规软件工具进行高效捕捉、管理和处理的数据集合，起源于互联网。

四大特征（4 个关键词）：

  • 数据体量大（规模大）
  • 数据类型多（多样且变化快）
  • 处理速度快
  • 应用价值高但价值密度低

应用：电商个性化推荐、导航地图、健康码、行程码、掌上公交等。

采集方法：网络采集法（网络爬虫）、传感器采集法、系统日志采集法。

处理过程：数据采集与预处理 → 数据存储 → 数据挖掘 → 数据呈现。

⭐ 重点

💡三、信息：数据中包含的意义

信息是数据中所包含的意义，必须依附于某种载体才能存储、表达和传播。典型信息：信号、通知、资讯、消息、短信、广告、新闻、市场行情、天气预报等。

三种经典定义（记住三位科学家）：

  • 香农：信息是能消除认识上的不确定性的消息。
  • 维纳：信息是一种资源，信息、物质、能量是人类赖以生存的三大资源。
  • 钟义信：信息是事物运动的状态与状态变化的方式。

信息的八大特征（考试高频，务必记牢）：

特征含义实例
价值性具有经济或精神价值天气预报指导穿衣、出行
载体依附性不能独立存在，需依附载体文字刻竹简、写纸上、存电脑
可处理性加工后产生新信息、增值卫星云图→天气预报
传递性可从一个地方传到别处冬奥会开幕式全球直播
共享性多人同时接收、可多次使用红绿灯信号每个司机都能看
时效性一定时间内有效，过期失效微信红包 24 小时未领自动退回
真伪性有真有假"空城计"、手机诈骗短信
价值相对性对不同人有不同价值酒驾扣分对司机重要、对学生无用

信息的载体：符号、语言、文字、图像、声音、动画、视频等。

📌 记忆口诀（信息八大特征）：
"价值依附可处理，传递共享讲时效，真伪相对记心间。"（价·依·可·传·共·时·真·相）
⭐ 重点🔥 难点

🧠四、知识 & 数据→信息→知识→智慧的关系

知识是对信息加工、提炼、分析的结果，能精准反映事物的本质，是可用于指导实践的认识、规律和经验。

🔍 例子：“标准气压下，冰水混合物的温度是 0℃”描述的是知识。公式、定理、感冒指数、身体健康指数、"血压正常范围""正常心率 60~100 次/分"都属于知识。

四者关系——由低到高的认知阶段：

数据 → 信息 → 知识 → 智慧
  • 数据：是信息和知识的基础（原料，最初阶段）；
  • 信息：是数据处理的结果（加工后有意义）；
  • 知识：是对信息加工、提炼的结果，反映本质（规律）；
  • 智慧：是知识的抽象和升华。

⚠️ 注意：数据与信息不是"相互包含"关系——数据是载体、信息是内涵。

📌 记忆口诀：
"数据是原料，信息是加工，知识是规律，智慧是升华。"
📝 教材真题精练（单元一 · 30 题）

✅单元一真题练习

🎯 第 1 课时 · 小结

  • 数据是符号记录（载体），信息是数据的内涵（意义），知识是对信息提炼出的规律。
  • 三者由低到高：数据 → 信息 → 知识 → 智慧（数据是基础、最初阶段）。
  • 信息八大特征：价值、依附、可处理、传递、共享、时效、真伪、相对。
  • 大数据四大特征：体量大、类型多、速度快、价值密度低。

第 2 课时

数制与进制转换

计算机只认识 0 和 1，学会十进制 ↔ 二进制互转是信息编码的基础。本课时配套教材单元二 30 道真题。

⭐ 重点

🔢一、二进制的基本概念

计算机内部所有数据都用二进制表示，只有 0、1 两个数码，能被机器直接识别。

运算规则：逢二进一、借一当二。同理，n 进制就是"逢 n 进一、借一当 n"（如四进制"逢四进一"、五进制"逢五进一"）。

位权（由低位到高位）：2⁰、2¹、2²、2³…… 即 1、2、4、8……

表示方式：在数末尾加字母 B，如 1101B 表示二进制。其余：D 十进制、O 八进制、H 十六进制。

组合状态数：n 位二进制有 2ⁿ 种组合（如 4 位二进制有 2⁴=16 种）。

⭐ 重点🔥 难点

➡️二、十进制 → 二进制（两种方法）

方法一：除 2 取余法（辗转相除法）——反复除以 2，取出余数，商作为下次被除数，直到商为 0，余数由下往上写。

🔍 例：35 → 100011B　35÷2=17 余1，17÷2=8 余1，8÷2=4 余0，4÷2=2 余0，2÷2=1 余0，1÷2=0 余1，余数倒序得 100011。

方法二：拆数法（凑数法）——按位权从大到小拆，每一步尽量大。

🔍 例：35 = 32 + 2 + 1 → 二进制 100011；　27 = 16 + 8 + 2 + 1 → 11011；　14 = 8 + 4 + 2 → 1110；　29 = 16 + 8 + 4 + 1 → 11101。

💡 通用方法：十进制转任意 R 进制（R=2、8、16），都用"除 R 取余、倒序排列"。

📌 记忆口诀：
"除 2 取余，余数倒着读；拆权凑数，从大往小拆。"
⭐ 重点

⬅️三、二进制 → 十进制（按权展开求和）

方法：按权展开，把各位数码乘以对应位权后相加。

🔍 例：(10111)₂ = 1×2⁰ + 1×2¹ + 1×2² + 0×2³ + 1×2⁴ = 1 + 2 + 4 + 0 + 16 = 23
🔍 例：(11010)₂ = 0 + 2 + 0 + 8 + 16 = 26；　(10101)₂ = 16 + 4 + 1 = 21
📌 记忆口诀：
"按权展开，乘了再加，位数从 0 开始数。"

👉 去 🛠 互动工具 里的"进制转换器"练一练！

📝 教材真题精练（单元二 · 30 题）

✅单元二真题练习

🎯 第 2 课时 · 小结

  • 计算机内部用二进制（0、1），规则"逢二进一、借一当二"；n 位二进制有 2ⁿ 种组合。
  • 十进制→二进制：除 2 取余（倒序） 或 拆数法（凑权）；十进制→R 进制用"除 R 取余"。
  • 二进制→十进制：按权展开求和。

第 3 课时

信息编码与存储单位

文字、符号在计算机里如何变成 0/1？掌握 ASCII 码、汉字编码流程和存储单位换算。本课时配套教材单元二后半部分真题。

⭐ 重点

🔤一、信息的编码

编码是指按预先规定的方法将文字、数字或其他数据转换为规定的符号组合。在计算机中，编码是指将符号、数字、文字、图像、声音和视频等对象按预先规定的方法编成二进制代码的过程。

编码的作用与意义（四点）：

  • 便于机器识别、存储、传输和处理；
  • 方便使用，提高数据利用率；
  • 节省存储空间；
  • 提高数据处理效率。
⭐ 重点

🔤二、ASCII 码

ASCII 码是美国国家信息交换标准代码，用于对英文字母（区分大小写）、数字 0~9、标点及控制字符编码。

  • 用 1 个字节表示 1 个字符，最高位固定为 0，实际只用 7 位，共能表示 2⁷ = 128 个字符。
  • 大小关系（务必记住）：空格 < 数字 < 大写字母 < 小写字母

常用十进制范围：

范围内容
0 ~ 31控制字符
32空格
48 ~ 57数字 0 ~ 9
65 ~ 90大写字母 A ~ Z
97 ~ 122小写字母 a ~ z
123 ~ 128英文标点符号、运算符号

🔍 推导："d"=100 → "g"=100+3=103；"C"=01000011 → "F"=01000011+11=01000110；"B"=01000010 → "F"=01000010+100=01000110；"C"=67 → "H"=67+5=72。
📌 记忆口诀：
"空 < 数 < 大 < 小"（空格最小，小写字母最大；数字 48 起、大写 65 起、小写 97 起）。
⭐ 重点🔥 难点

🀄三、汉字编码流程

汉字从输入到输出，不同环节用不同编码：

输入码 → 机内码 → 国标码(GB2312) → 输出码(字形码)
  • 输入码：如拼音、五笔；
  • 机内码：汉字在机器内部存储、加工、传送使用的代码；
  • 国标码（GB2312）：一种交换码；
  • 输出码（字形码）：用字形点阵表示。

存储：存储一个汉字的机内码或国标码用 2 个字节，存储 1000 个汉字约占 2KB（1024 个汉字国标码 = 2048B = 2KB）。

🔍 字形点阵："日"字 8×8 点阵存储容量 = 8×8÷8 = 8B（÷8 是把"位"换算成"字节"，1B=8 位）。位图编码规则：黑记 1、白记 0，从左到右逐位编码。
📌 记忆口诀：
"输入 → 机内 → 国标 → 输出"，简称 "输机国出"；一个汉字机内码/国标码 2 字节。
⭐ 重点

💾四、信息存储单位

最小单位是位（bit，简记 b，即比特），基本单位是字节（Byte，简记 B），1B = 8bit。

1B = 8bit　|　1KB = 1024B　|　1MB = 1024KB　|　1GB = 1024MB　|　1TB = 1024GB
🔍 1KB 能存 1024 个英文字符（每个 1B），最多存 512 个汉字（每个 2B）；10000 个英文字母约 10KB。
📌 记忆口诀：
"1B 等于 8 位，1024 进一级，K、M、G、T 排排坐。"
📝 教材真题精练（单元二编码部分 · 含存储单位）

✅编码与存储单位真题练习

🎯 第 3 课时 · 小结

  • ASCII 码：7 位、128 字符，大小关系"空格 < 数字 < 大写 < 小写"。
  • 汉字编码：输入码 → 机内码 → 国标码 → 输出码，机内码/国标码各占 2 字节。
  • 存储单位：1B=8bit，每级 ×1024，从 B 到 KB、MB、GB、TB。

第 4 课时

声音与图像编码

声音、图像如何变成数字信号？掌握"采样→量化→编码"三步骤和容量计算公式。本课时配套教材单元三 25 道真题。

⭐ 重点

〰️一、模拟信号与数字信号

  • 模拟信号 / 模拟数据：用连续变化的物理量表达，相对不稳定，易受干扰失真（如声音、图像、视频、温度、压强）。
  • 数字信号 / 数字数据：随时间变化是离散、不连续的，用二进制 0 和 1 表示。
  • 模拟信号与数字信号可以相互转换（数字数据也能转回模拟数据）。

数字化三步：

采样 → 量化 → 编码
📌 记忆口诀：
"先采样、再量化、最后编码。"（"采量编"）
⭐ 重点🔥 难点

🎵二、声音数字化

  • 采样：每隔一段时间在波形上取一个幅度值，1 秒内采样次数叫采样频率，频率越高保真度越高。
  • 量化：用二进制数表示采样得到的幅度值（取最接近的整数），量化位数越大保真度越高。
  • 编码：把量化后的数据转化为二进制数。

采样频率越高、量化位数越大 → 保真度越高、质量越好，但数据容量越大。

声音容量(B) = 采样频率 × 量化位数 × 声道数 × 时长 ÷ 8
🔍 例：22.05kHz、16 位、10 秒、双声道：22.05×1000×16×10×2÷8÷1024 ≈ 861.3KB。
🔍 例：22.05kHz、16 位、5 秒、双声道：22.05×1000×16×5×2÷8÷1024 ≈ 430.7KB。（注意 kHz 先 ×1000 换成 Hz）
📌 记忆口诀：
"频率乘位数，乘声道乘时长，最后除以 8。"
⭐ 重点🔥 难点

🖼三、图像数字化

图像数字化同样分采样、量化、编码三步：采样是把图像分割成像素点；量化是用二进制表示每个像素的颜色/亮度；编码是记录量化数据。

  • 像素：图像分割成的离散点。
  • 颜色位数（位深度）：表示像素点颜色/亮度的位数，颜色种数 = 2ⁿ（n 为颜色位数）。
🔍 黑白图像 1 位（2¹=2 色）、16 色需 4 位（2⁴）、256 色需 8 位（2⁸）、24 位真彩色；5 位可表示 2⁵=32 色。
图像容量(B) = 分辨率(宽×高) × 颜色位数 ÷ 8
🔍 例1：20×30、24 位：20×30×24÷8 = 1800B。　例2：20×30、16 色（4 位）：20×30×4÷8 = 300B。　例3：10×20、16 色：10×20×4÷8 = 100B。　例4：20×10、24 位：20×10×24÷8 = 600B。
📌 记忆口诀：
"分辨率乘位数，除以 8 得容量；颜色种数 2 的 n 次方。"
⭐ 重点

🖋四、位图 vs 矢量图 & 常见文件扩展名

类型组成优点缺点
位图（点阵图）由像素组成色彩丰富、逼真反映自然景物放大易失真、文件容量大
矢量图（向量图）由线条+色块组成放大不失真、文件容量小色彩单调、不够丰富
📌 记忆口诀：
"位图放大糊，矢量放大清；位图色彩富，矢量色彩单。"

常见文件扩展名（考试常考格式归类）：

类型扩展名
文本txt、doc/docx、ppt/pptx、wps
声音wav、mp3、wma、mid、au、ra（wav 未压缩、音质好、容量大）
图像jpg/jpeg、gif、bmp、png、tif/tiff、psd（bmp 未压缩、容量大）
视频avi、mpg、wmv、mp4、asf、mov
其他rar/zip（压缩）、xls/xlsx（表格）、pdf（文档）
🔍 wav→mp3、bmp→jpg 都是缩小容量（转为压缩格式）。

✅单元三真题练习

🎯 第 4 课时 · 小结

  • 模拟→数字三步骤：采样 → 量化 → 编码。
  • 声音容量 = 采样频率 × 量化位数 × 声道数 × 时长 ÷ 8。
  • 图像容量 = 分辨率 × 颜色位数 ÷ 8；颜色种数 = 2ⁿ。
  • 位图放大失真但色彩丰富，矢量图放大不失真但色彩单调。

🎯高频考点规律总结

① 信息八大特征辨析（21 题，最高频）——抓题干里的"场景关键词"对号入座：

特征题干关键词典型场景
价值性指导决策、有用途、带来好处看天气预报出海、用健康数据优化教学
载体依附性依附于、刻在、写在、存进文字刻竹简、存电脑
可处理性分析、加工、处理、筛选成绩分析找问题、身份证提取性别
传递性传到、传播、播报消息传遍全国、直播
共享性多人同时、共同、下载、群发微信群里发通知、资源下载
时效性过期、过时、随时间变化优惠券过期、旧地图、旧天气
真伪性真假、诈骗、假象"明修栈道暗度陈仓"、诈骗短信
价值相对性对不同人价值不同酒驾扣分对司机重要、对学生无用
📌 口诀："价值依附可处理，传递共享讲时效，真伪相对记心间。"

② 数字化三步骤 + 容量计算（13 题）——先记顺序，再套公式：

  • 三步顺序固定：采样 → 量化 → 编码（考"第一步是采样""不包括输入/压缩"）。
  • 声音容量 = 采样频率 × 量化位数 × 声道数 × 时长 ÷ 8，kHz 要先 ×1000 换成 Hz。
  • 图像容量 = 分辨率（宽×高）× 颜色位数 ÷ 8。
  • 颜色种数 = 2ⁿ：黑白 1 位、16 色 4 位、256 色 8 位、7 位 128 色、6 位 64 色。
📌 口诀："先采样、再量化、最后编码；容量=各项相乘再除以 8。"

③ 数据 / 信息 / 知识辨析（12 题）——三者层层递进：

  • 数据：描述客观事物的符号记录（如"160"、年平均气温、健康码）。
  • 信息：数据所包含的意义（如"小明身高 160 厘米"、天气预报、股市行情）。
  • 知识：经过提炼的规律/定律（如质量守恒定律、"正常心率 60~100"）。
  • 数据特点：固定（区号）/会变化（气温）/随机（骰子、彩票）。
📌 口诀："数据是符号，信息有意义，知识是规律。"

④ 进制转换（9 题）：

  • 二进制 → 十进制：按权展开求和（如 11011 = 16+8+2+1 = 27）。
  • 十进制 → 二进制：拆数法（凑 16/8/4/2/1）或除 2 取余倒序。
  • 二进制运算：逢二进一（如 0101+0111 = 1100）。
  • n 进制规则：逢 n 进一（六进制逢六进一）。

⑤ 存储单位换算（8 题）——两大易错点：

  • 1B = 8bit，相邻单位 ×1024 进一级（1KB=1024B、1MB=1024KB、1GB=1024MB、1TB=1024GB）。
  • 一个汉字占 2 字节、一个英文字符占 1 字节：1000 汉字≈2KB，5000 汉字≈10KB，2000 汉字≈4KB。
  • 最小单位是位（bit）、基本单位是字节（Byte）。

⑥ ASCII 码（5 题）：

  • 7 位编码、共 128 个字符，用 1 字节存储。
  • 大小关系：空格 < 数字 < 大写字母 < 小写字母。
  • 相邻字母 ASCII 码连续：已知一个字符的码值，按字母表位置加减差值即可推出（如 "d"=100 → "g"=103）。
🔥 易错点

⚠️答题技巧与易错提醒

  • "时效性" vs "价值相对性"：强调"过期/过时"选时效性；强调"对不同人价值不同"选价值相对性。
  • "共享性" vs "传递性"：强调"多人同时接收、可多次使用"选共享性；强调"从一处传到另一处"选传递性。
  • "载体依附性" vs "数据"：问"信息不能独立存在、需依附载体"选依附性；问"记录客观事物的符号"选数据。
  • 容量计算单位陷阱：kHz 要 ×1000 换 Hz；结果为 B 时若要 KB 记得再 ÷1024；16 色 = 4 位（2⁴），不是 16 位。
  • 汉字 vs 英文字符：汉字 2 字节、英文 1 字节，算"能存多少个"时别搞混。
  • 排除法：选择题先排除明显"设备/载体"项（计算器、光盘、显示屏不是数据），再排除"过时表述"。
