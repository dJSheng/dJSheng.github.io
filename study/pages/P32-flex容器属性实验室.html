CSS 代码 · flex容器属性
/* flex 容器 */
.container {
display: flex;
flex-direction: row;
justify-content: flex-start;
align-items: stretch;
flex-wrap: nowrap;
height: 280px;
border: 2px dashed #185FA5;
}
 
/* flex 子项 */
.item {
width: 70px;
background: #185FA5;
}
实时预览 · 切换属性观察5个子项排列变化
flex-direction 主轴方向
决定主轴方向，子项排列方向
justify-content 主轴对齐
子项在主轴上的对齐分布方式
align-items 交叉轴对齐
子项在交叉轴上的对齐方式
flex-wrap 换行控制
子项过多时是否换行
📌
核心知识点
flex-direction定主轴方向，justify-content管主轴对齐，align-items管交叉轴对齐，flex-wrap管换行
⚠️
常见错误
混淆justify-content和align-items：前者管主轴，后者管交叉轴，direction改变时轴向也变
💡
拓展思考
导航栏用justify-content:center居中，链接栏用space-between两端对齐，卡片列表用wrap换行
❤
思政小贴士
flex是弹性布局适应不同屏幕。技术要适应人不是人适应技术——这就是"以人为本"
