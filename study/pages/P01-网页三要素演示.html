HTML 结构
骨架 —— 定义内容结构
CSS 表现
外衣 —— 美化页面外观
JavaScript 行为
交互 —— 实现动态效果
提示：先开 HTML 看裸页面，再加 CSS 看变美，最后加 JS 看能动。体会三要素的层层叠加。
核心知识点
网页 = HTML结构 + CSS表现 + JS行为。三者分离，各司其职。
常见错误
初学者常把样式写进HTML标签里（内联样式），应尽量用CSS分离表现与结构。
拓展思考
如果只开CSS不开HTML，页面会怎样？为什么说"结构是基础"？
思政小贴士
HTML是骨架（内在），CSS是外表（外在），做网页要内外兼修，做人也要"文质彬彬"。
