对比演示型 项目⑤任务5
CSS 代码 · 三种隐藏对比
/* 方式一：display:none */
/* 彻底消失，不占位，下方上移 */
.box1 {
display: block;
}
 
/* 方式二：visibility:hidden */
/* 隐形留位，占位保留空白 */
.box2 {
visibility: visible;
}
 
/* 方式三：overflow:hidden */
/* 裁剪溢出，超出部分隐藏 */
.box3 {
overflow: visible;
height: 100px;
}
实时预览 · 三个盒子并排对比隐藏效果
对比控制面板
盒子1：display
display:none 彻底消失不占位
盒子2：visibility
visibility:hidden 隐形占位
盒子3：overflow
overflow:hidden 裁剪溢出内容
效果说明

display:none
盒子1消失，盒子2、3会左移填补空位

visibility:hidden
盒子2隐形但保留位置，盒子1、3不动

overflow:hidden
盒子3超出高度的文字被裁剪

📌
核心知识点
display:none不占位，visibility:hidden占位，overflow:hidden裁剪溢出内容
⚠️
常见错误
下拉菜单误用visibility:hidden导致隐藏时仍占位撑开导航栏布局
💡
拓展思考
overflow:hidden还能清除浮动(BFC)、实现文字省略号、配合resize实现自定义滚动
❤
思政小贴士
知道何时显示何时隐藏是智慧。display:none彻底退场visibility:hidden留有位置，人也要懂进退时机
